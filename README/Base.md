# 기본 수칙

1. Branch
    
- Branch는 오직 6개로만 구성하여 사용할 예정이며, 다음과 같은 용도로 사용한다.
    - `Main` : 최종 / 4명의 대면 혹은 원격 허락 하에 수정 가능
    - `Develop` : 팀원 모두의 코드를 취합한 환경 / Main 이전 모두가 다룰 수 있는 Demo
        - `Song`
        - `Min`
        - `Young`
        - `Jun`   : 각 중간글자로 브랜치의 이름을 명명하며, 본인의 코드를 작성 후 올린다.
