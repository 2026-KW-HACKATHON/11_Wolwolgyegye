# 코드 작성

코드 작성 간에 다음 규칙을 따른다.

1. 웹/앱

- 웹 관련 언어 `HTML + CSS + JAVASCRIPT` 로 프런트를 다루지만,  
모바일(ios, 안드로이드)와 PC는 근본적으로 차이가 있다.
- 단순히 CSS를 `px`단위와, `%`단위의 차이로 구분하여 다룰 수 있겠지만,  
세로가 긴 모바일과 가로가 긴 PC는 그 차이가 명확하다 볼 수 있다.
- 이를 넘어서, 손가락을 이용한 터치와 마우스를 활용한 클릭은 엄연한 차이가 존재하므로,  
`내용은 같게`하되, `구현의 방식은 다르게` 구현한다.
- 다음과 같은 5가지의 상황들을 고려한다.
    - 모바일 (ios, 안드로이드) 가로모드
    - 모바일 (ios, 안드로이드) 세로모드
    - 태블릿 (ios, 안드로이드) 가로모드
    - 태블릿 (ios, 안드로이드) 세로모드
    - PC (데스크탑, 노트북 등)


2. 작업 구조

- `Base.md`에서 사전에 명명한대로, 순서도에서 카테고리라는 커다란 틀 내에서  
여러가지 하위 목록들이 존재하고 하나하나 전부 객체로 가정하여 각자 구현한다.
- 이때, 객체로 구현하기에 서로 간에 상호작용할 인자에는 미리 선언할 이유가 없지만,  
공통적으로 활용하는 `데이터 셋`은 그 이름을 통일하고 미리 합의해야한다.


3. 테마
- 이후 `설정`에서 통합적으로 바꿀 수 있음을 감안하더라도,  
`CSS를 통한 색상 지정 하드코딩`을 지양하고 `특정 키워드로 선언해두는 것으로` 함.
- 나중을 위한 과정이니 참고 바람.
