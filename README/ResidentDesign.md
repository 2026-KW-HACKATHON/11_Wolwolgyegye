# 월계1동 주민을 위한 모바일 홈 디자인

## 방향

**가까운 가게의 소식을 발견하고, 위치를 확인하고, 문의하는 동네 생활 화면.**

네이버지도에서 참고한 것은 지도와 피드를 오가는 사용 방식이다. 화면의 색, 문구, 게시글 구성은 월월계계의 동네 상권 서비스에 맞춘다.

## 코드 경계

> 레이아웃 개편 이후: 지도는 앱 셸(`layout/AppShell`)이 모든 카테고리 뒤에 깔고, 동네 소식은 그 위에 올라오는 1차 탭 중 하나가 되었다.
> 손잡이 드래그는 `layout/SwipePanel`, 배경 지도는 `shared/map/MainMap.tsx` 로 옮겼다.

- `frontend/src/features/recommend/RecommendPage.tsx`: 동네 소식 1차 탭 내용 (가게 선택 시 지도에 표시)
- `HomeScreen.tsx`: 기존 소스에서 소식 조회, 검색·분류, 바로가기
- `FeedPostCard.tsx`: 주민이 읽는 게시글 카드와 가게 찜·지도 연결
- 사진 없는 게시글의 그림은 `features/store-feed/CategoryArt.tsx`(세부 분류별 SVG 일러스트)를 함께 쓴다
- `recommend.css`: 동네 소식 전용 스타일 (탭 폭 기준 @container)

공통 테마와 헤더·내비게이션 아이콘만 함께 다듬었다. 다른 팀원의 카테고리 폴더, 데이터 타입, DB 계층, 배포 설정은 바꾸지 않는다.

## 실제 서비스와 구분할 점

- 현재 소식에는 예시 데이터가 포함되어 있다. 운영 가게·모집 상태로 오해하지 않도록 예시임을 표시한다.
- 예약·결제는 이 디자인 작업의 범위가 아니다.
- 거리 수치는 실제 사용자의 위치가 아닌 지도 기준점과 가게 좌표 사이의 직선거리다.

## 로컬 검증

- TypeScript 검사와 Vite 프로덕션 빌드
- 모바일 390×844, 작은 화면 320×640, 가로 화면 844×390, PC 1280×900 확인
- 검색 결과 및 빈 결과, 가게 찜과 찜 분류, 게시글→지도 선택, 지도 분류 유지, 손잡이 드래그 확인
- 기존 원데이클래스 상세 화면 및 전화 문의 안내로 연결 확인
