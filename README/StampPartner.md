# 스탬프 · 제휴 가게 화면

## 스탬프 (`/coupon`)

- **나의 스탬프 지갑**: 모은 도장 수, 받을 수 있는 선물, 적립 중인 가게 수를 맨 위에 보여준다. 선물을 받을 수 있는 가게(없으면 선물까지 가장 가까운 가게)를 바로 열 수 있다.
- **목록**: 검색(가게·업종·선물), 상태별 보기(전체·선물 받기·모으는 중·찜한 가게), 정렬(선물 가까운순·가까운 가게순·최근 적립순·이름순).
- **적립판** (`/coupon?store=ID`): 도장마다 적립 날짜가 찍힌다. 선물 진행률, 적립 내역(`stamp_transactions` 모양), 가게 정보와 위치 지도, 적립·교환 안내가 있다.
- **적립 코드 → 도장**: 결제할 때 6자리 코드를 보여주고 직원이 확인하면 적립되는 흐름이다. 코드는 3분마다 바뀐다.
- **선물 교환권**: 다 모으면 교환권을 보여주고, 교환하면 새 적립판이 시작된다.
- **시연 모드**: 직원 확인 대신 버튼으로 적립·교환을 해 볼 수 있다. 기록은 이 브라우저(localStorage `wolwol.stamp.demo.v1`)에만 저장되고, 목록 아래 "시연 기록 지우기"로 지운다.

## 제휴 가게 (`/partner-stores`)

- **내 소속**: 단과대 칩으로 고르고, 칩마다 해당 가게 수가 보인다. 선택은 이 기기에만 저장한다.
- **가게 이름을 누르면** 카드 안 혜택 설명 아래에 위치 지도, 주소, 영업시간, 기준점 기준 방향·거리가 펼쳐진다. 여러 개를 동시에 펼칠 수 있다.
- **바로 연결**: `/partner-stores?store=ID`로 들어오면 그 가게를 맨 위에 두고 지도를 펼친다. 스탬프 적립판과 제휴 카드는 서로 오가는 링크로 연결돼 있다.
- **혜택 카드**: 티켓 모양 혜택, 대상 단과대 수, 예시 가격, 스탬프 적립판 링크가 있다.
- **혜택 자세히 창**: 기존 기능(이용 조건, 메뉴 할인 계산, 안내 화면)은 그대로 두고 위치 지도를 더했다.

## 지도 (`shared/map/StoreMap.tsx`)

- **지도**: 카카오맵은 쓰지 않는다. 상세에는 위치 약도만 그리고, 실제 위치는 앱 뒤의 배경 지도에서 보여준다.
- **위치 약도**: 기준점과 가게 좌표로 방향·직선거리만 계산한 그림이고, 도로는 그리지 않는다고 화면에 표시한다.
- **지도에서 보기**: 제휴 가게 상세의 위치 버튼은 상세 창을 닫고 배경 지도에서 그 가게를 선택한다.
